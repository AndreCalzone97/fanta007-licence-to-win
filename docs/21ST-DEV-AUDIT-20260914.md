- **Not claimed as exact:** OriginKit components and any 21st component whose source was not retrieved. The 21st component-code quota is exhausted in this workspace, so the audit does not pretend that local equivalents are vendor-faithful source copies.

## FANTA007 Agent reference

The supplied pose sheet is treated as an **asset/state reference**, not as a page layout. The current code already has verified local states for `hero`, `thinking`, `positive`, `warning` and `critical` in `AgentIllustration`. The sheet also suggests scouting, analysis, success, verdict, loading, empty and error states; those are not invented in this pass because separate production assets and a selected 21st motion model are not yet available. This keeps the character coherent without silently replacing the supplied artwork with unrelated UI imagery.
