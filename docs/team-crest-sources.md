# Team crest sources

The MVP resolves club crests centrally in `frontend/src/config/teamCrests.ts` and uses the original Wikimedia/Wikipedia file URLs. `TeamCrest` always falls back to club initials if a remote asset fails.

## Deployment note

Club crests can also be protected as trademarks. Wikimedia's file status does not grant blanket commercial-use rights. Before a public or commercial release, review each mark and replace assets marked `fair-use` with licensed club/media-kit assets or approved neutral crests.
