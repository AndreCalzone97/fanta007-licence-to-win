# UX Flow

Il flusso corrente è:

```text
Landing
→ Inizia la missione
→ nome squadra
→ partecipanti
→ modalità
→ budget
→ obiettivo
→ Missione accettata
→ Dashboard
→ cerca giocatore
→ applica filtro ruolo opzionale
→ apri mini scheda
```

La configurazione lega è conservata in `localStorage` con chiave `fanta007.league.v1`.
