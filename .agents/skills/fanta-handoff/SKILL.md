# FANTA007 handoff

End with a plain-text `CHATGPT HANDOFF` block of at most 8 lines by default (at most 10 if the PM requests 10 for the task), self-contained for ChatGPT Free.

Cover only the applicable facts: completed work, files/changes, incomplete work, test status, problems, exact next step, PM decisions, and public links that directly help. State `not run` or `not verified` rather than inferring success. Do not include private local URLs, secrets, or long internal file paths unless needed to resume work.

Use this alongside the primary mission skill; it is an output format, not a license to do extra work or run every check.
